# iOS validation matrix

This is a manual test plan for a dedicated signed iOS build of Still. It is not a release approval or a request to erase anyone's real data. Use a dedicated test device/build, disposable local records, fictional content, and test provider accounts. Do not run destructive privacy cleanup against a personal or production workspace. Every row below is **NOT RUN**; web and unsigned JavaScript exports do not count as native iOS evidence.

## Build configuration and module packaging

The local `check:ios-config` static gate passed, but the following native packaging checks have not been run:

| ID | Preconditions and steps | Expected result and evidence | Status |
| --- | --- | --- | --- |
| CFG-01 | On a macOS/Xcode build host with the chosen Expo project and Apple team, install CocoaPods dependencies and build development and preview profiles. Inspect the generated app's embedded StillPrivacy module and its runtime identity; also inspect a production/store-classified archive before any submission. | The module compiles and is embedded in each intended custom build; development and preview classification match their EAS profiles; Expo Go remains unsupported. Capture pod installation/build logs, profile, archive classification, and module startup result. Static JavaScript or Expo config checks do not count. | NOT RUN |

## Build and capture

| ID | Preconditions and steps | Expected result and evidence | Status |
| --- | --- | --- | --- |
| IOS-01 | Install the signed custom build with bundle ID `com.still.voiceassistant`; inspect its linked Still privacy identity module and launch the app. Compare identity across JS reload and a full process relaunch. Also open Expo Go as a negative control. | The custom build reports a process-stable identity for the app process and a new identity after a full process restart. Expo Go or a missing/mismatched module reports unsupported and offers no full-delete action. Record build/version, bundle ID, module result, and launch boundaries. | NOT RUN |
| AUD-01 | On a disposable workspace, deny microphone permission, then retry with permission granted. | Denial creates no recording and no false active state. Grant permits one explicit start. Record the permission choice and UI/native status transitions. | NOT RUN |
| AUD-02 | Start, explicitly pause, wait, explicitly resume, then stop a short recording. Check audio/session state while paused and after resume. | Pause leaves capture inactive and the UI paused; it does not restart on its own. Resume alone re-enables the recording mode and capture. Stop yields one truthful final duration and one saved clip. Capture UI plus observed state/timestamps. | NOT RUN |
| AUD-03 | Pause, background Still, foreground it without touching Resume. Repeat after an active recording is interrupted by a call/Siri, covering interruption end both with and without the system resume option. | An explicitly paused recording remains paused across foregrounding. For active interruption, visible state, timer, `isRecording`, `canRecord`, and recorder status agree with the implemented resume policy; no phantom start or false “recording” state remains. Capture each transition and interruption option. | NOT RUN |
| AUD-04 | Rapidly stop while backgrounding; repeat with a short saved clip and a disposable active clip. | Stop/reconciliation does not save twice, lose a completed file, resume capture, or report idle while native capture remains active. Record stop result, URI identity only as a test artifact, duration, and final states. | NOT RUN |
| AUD-05 | Record a short M4A, stop and save, close/reopen Still offline, then play it. Separately exercise explicit discard on an unsaved clip. | Saved audio remains playable offline; discard removes only the unsaved clip. The app never claims saved audio is gone unless removal is verified. Keep the test clip and note identifiers in a private test log only. | NOT RUN |
| AUD-06 | With disposable clips, induce media-services reset, changed/missing URI, stop failure, audio-mode reset failure, and status-read failure. Exercise retry/recovery only as the UI permits. | The original saved recording is retained; a failed or ambiguous stop does not produce false idle or release the capture lease early. Recovery never saves the wrong or changed URI and never resumes capture. Capture fixed user-facing status and native state evidence. | NOT RUN |
| AUD-07 | On a disposable recording, test the configured maximum and just below/at/above the applicable hard cap. Check fractional duration and final native completion status. | The measured final duration is truthful and consistent across native status, note save, and any later validation. A clip cannot silently cross the save/upload cap or be made to appear shorter by clamping. Record exact measured durations and resulting user-facing behavior. | NOT RUN |
| AUD-08 | Record and save a short clip. Start and save a second clip, then reopen and play the first. Also pause/resume the first capture before saving and inspect that Resume did not prepare a new file. | Each new capture uses a distinct file URL; preparing the second capture does not alter the first saved file's bytes or playback. Pause/resume continues the same in-progress capture. Record redacted URI identity as a test artifact and compare first-file size/hash before and after the second capture. | NOT RUN |
| AUD-09 | On a disposable workspace, start a recording and inspect the ordering of recording-mode disablement, recorder preparation, durable pending-record commit, fresh original-file identity/reset check, mode enablement, and the first frame. Repeat with permission denial and stale identity. Terminate the app after the durable commit and reopen recovery; separately terminate before commit. | No frame is recorded before journal commit and fresh identity/reset checks. Termination after commit leaves a record available for inspection without saving or duplicating a note. Termination before commit may leave an unjournaled prepared file and must not be described as recoverable by the journal. Capture the native timeline and reopened safe recovery status. | NOT RUN |
| AUD-10 | Exercise stop, pause, resume, status inspection, and privacy-cleanup contention on a dedicated build. Include a stop that resolves without stopping, a status-read failure, and a delayed cleanup/writer lease. | The app retains the writer until native termination is proven, does not take a nested writer lock, and does not claim idle or save while capture may remain active. Verify recovery and cleanup can proceed only after the owning I/O settles or a verified process restart. | NOT RUN |
| AUD-11 | Inspect an interrupted recording repeatedly, including unknown duration, missing audio, and a duration above 600 seconds. Test a valid fractional-duration clip within the cap, then explicitly save, export, discard, and cancel the platform share sheet on disposable copies. | Unknown duration is not guessed; missing/over-limit files are not saved. Save consumes only the exact inspected recording into one matching note. Export/share cancellation does not delete or replace the original. Record exact file duration and the resulting recovery status after each action. | NOT RUN |
| AUD-12 | Test a clip below, at, and above the configured duration limit, and below, at, and above the 600-second hard local limit. Include a device under realistic load and delayed native status updates. | The local save result reflects the measured recording, never a clamped duration. The configured Speech limit is disclosed separately from the local save limit. Capture the decoded media duration, app status, note duration if saved, and Speech eligibility. | NOT RUN |

## Evidence record

For each executed row, record date/time, device model and iOS version, signed build/version, test ID, disposable-data setup, steps, expected versus observed result, relevant redacted logs/screenshots, and pass/fail/blocked status. Keep tokens, keys, personal data, raw audio, private file paths, and full account identifiers out of this document. No tests have been executed or results supplied by this matrix.
