# iOS validation matrix

This is a manual test plan for a dedicated signed iOS build of Still. Phase 27 adds source and automated coverage for local notification-tap routing, but no device validation or release approval. It is not a request to erase anyone's real data. Use a dedicated test device/build, disposable local records, fictional content, and test provider accounts. Do not run destructive privacy cleanup against a personal or production workspace. Every row below is **NOT RUN**; web and unsigned JavaScript exports do not count as native iOS evidence.
